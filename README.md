# Link Combiner - Chrome Extension

Main URL বা ডোমেইনের সাথে একাধিক ইউজারনেম/আইডি জোড়া লাগানোর জন্য একটি প্রফেশনাল এক্সটেনশন।

---

## 🚀 ক্রোম ব্রাউজারে এক্সটেনশনটি কিভাবে ইনস্টল করবেন:

1. **Google Chrome** বা **Brave / Edge** ব্রাউজার খুলুন।
2. ব্রাউজারের অ্যাড্রেস বারে যান এবং লিখুন:
   ```text
   chrome://extensions
   ```
3. পেজের উপরের ডান কোণে থাকা **"Developer mode"** অপশনটি অন (Enable) করুন।
4. উপরের বাম কোণে থাকা **"Load unpacked"** বাটনে ক্লিক করুন।
5. আপনার কম্পিউটারের এই ফোল্ডারটি সিলেক্ট করুন:
   ```text
   C:\Users\Mizan YT\Desktop\Extention
   ```
6. ব্যাস! এক্সটেনশনটি সাথে সাথে ইনস্টল হয়ে যাবে। ব্রাউজারের এক্সটেনশন পিন (Pin) আইকনে ক্লিক করে এটি সহজে ব্যবহার করতে পারবেন।

---

## 🛠️ কিভাবে ব্যবহার করবেন:

1. **Box 1 (Main URL):** আপনার মূল URL টি দিন (যেমন: আপনার দেওয়া `https://um.mos.ru/uploads/...&id=`)।
2. **Box 2 (Usernames / IDs):** 
   - **বক্সে লিখুন:** প্রতি লাইনে ১টি করে ইউজারনেম পেস্ট করুন।
   - **ফাইল আপলোড:** অথবা `.txt` ফাইল সিলেক্ট/ড্র্যাগ অ্যান্ড ড্রপ করুন।
3. **Generate Links বাটনে ক্লিক করুন:**
   - সাথে সাথে সবগুলো লিংক স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে।
4. **সহজ একশনে ডাউনলোড বা কপি করুন:**
   - **Copy All:** সবগুলো লিংক ১ ক্লিকে কপি হবে।
   - **Save File:** `.txt` আকারে ডাউনলোড হবে।
   - **Open in Browser:** ব্রাউজার ট্যাবে ওপেন হবে।
